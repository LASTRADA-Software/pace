# Third-party roots: the directories of this repository that hold source copied from
# elsewhere and not owned here (#1370). THE one answer to "is this path first-party?".
#
# Every tree-wide enumerator -- a script that lists the repository's files rather than
# naming a directory of its own -- reads this file instead of restating it. An
# enumerator that had not learned about a root INCLUDED it by default, so third-party
# sources were linted, formatted, scanned and counted as this project's own, silently
# and green. Importing `vendor/` needed five enumerators told separately, and review
# found three of them. `ctest -R third-party-roots` derives the enumerators and refuses
# one that neither reads this file nor carries a reasoned exemption.
#
# Format, readable by bash 3.2 and by `cmake -P` alike:
# - one root per line, relative to the repository root, with no leading `/`, no trailing
#   `/` and no `..`;
# - `#` starts a comment, to the end of the line; blank lines are ignored;
# - a file naming no root is REFUSED by both readers, never read as "nothing is
#   third-party", which would hand every vendored file to every enumerator.
#
# Readers: `third_party_roots` in `scripts/lib/third-party-roots.sh`, and
# `pace_third_party_roots` in `scripts/lib/CheckCommon.cmake`.
#
# A root also has to be named in `.clang-format-ignore`, which clang-format reads for
# itself; the check refuses a root that is missing there.
#
# A root is the COPY, not the directory holding copies. `vendor/monocypher`, never `vendor`:
# `vendor/VENDOR.md` and `vendor/MANIFEST` are written here, so "is `vendor/MANIFEST`
# first-party?" is yes -- and a root of `vendor` answers no,
# which drops this project's own build glue from every scan that reads this file. The
# next import is its own row.
#
# Every root is also a verbatim copy: `scripts/check-vendor-verbatim.cmake` hashes each one
# into `vendor/MANIFEST`, and `scripts/check-vendor-figures.cmake` requires `vendor/VENDOR.md`
# to describe each one. So a row here is the whole of adding a root to those checks too.
