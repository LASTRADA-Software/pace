After installing

Open a new terminal window. The installer adds /opt/fastcached/bin to the system PATH through /etc/paths.d, which macOS only reads when a login shell starts — a terminal that is already open will not see it. Both tools are also symlinked into /usr/local/bin, so in practice they are reachable straight away in most shells.

Check that the daemon is running:

    launchctl print gui/$UID/software.lastrada.fastcached

or, for the system-wide service:

    sudo launchctl print system/software.lastrada.fastcached

Configuration

The daemon reads /opt/fastcached/etc/fastcached.yaml. Every setting in it is commented out and shows its built-in default, so the file as shipped behaves exactly like no config at all. Your edits are preserved across upgrades — only fastcached.yaml.default beside it is replaced.

After changing it, restart the service:

    launchctl kickstart -k gui/$UID/software.lastrada.fastcached

Removing Pace

macOS packages have no built-in uninstaller, so one ships with this package:

    sudo /opt/fastcached/bin/pace-uninstall

It stops and unregisters the launchd jobs, removes /opt/fastcached, the PATH entry and the symlinks, and forgets the package receipts. Your own cache and logs under ~/Library are left in place.
